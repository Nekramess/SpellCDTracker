# SpellCDTracker

Icons-only cooldown, buff, totem and pet/imbue tracker for World of Warcraft: Forever, for every class, with per-class and per-spec settings and a combat-only swing timer.

## Install
Copy this folder into `Interface/AddOns/SpellCDTracker`, then restart the game or `/reload`.

## Commands
- `/scdt` options, `/scdt spells` Tracked spells, `/scdt edit` move frames, `/scdt debug` diagnostics
